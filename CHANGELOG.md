# Changelog

All notable changes to Snowball Effect are documented in this file.

The format follows Keep a Changelog and the project uses four-part versions.

## [0.1.0.0] - 2026-08-25

### Added

- Added a compact `BALLS` CRT genealogy with bottom-to-top nodes, connectors, discovery reveal, and stage carryover icons.
- Added dedicated Galactic Galaxy Cluster gameplay and CRT assets plus focused import-fallback verification.
- Added restrained near-field Black Hole motion cues with normal and reduced-effects presentations.

### Changed

- Aligned the Planetary Galaxy, Galactic Event Horizon, and Galactic Black Hole FIRST CONTACT portraits with their approved visual identities without replacing the in-game assets.
- Refined Galactic Galaxy and Galaxy Cluster runtime artwork and updated their asset manifests.
- Removed the legacy wide Black Hole point/ring language in favor of local arc and trailing cues.

### Fixed

- Prevented the optional Galaxy Cluster CRT image from blocking game startup before its Godot import cache exists.
- Updated stale Ground and Planetary asset verifiers to the current approved texture contracts.
