# Audio Attribution

## Provenance

All `.ogg` files currently under this directory were generated as original,
project-specific sound effects through Codex in a separate project session on
2026-08-13.

They were created for **Snowball Effect** and are intended for use in this
project's game build and public Web release.

## Third-party assets and licenses

- No third-party audio asset, sample pack, or external recording was knowingly
  imported for the current files.
- No third-party attribution or separate asset license is required for the
  current audio set.

## Current asset groups

- S6 gameplay candidates: `merge_t0` through `merge_t3`, `cashout_t0`,
  `cashout_high`, `settlement_start`, `settlement_finish`, `stage_clear`, and
  `scale_shift`.
- UI candidates: `ui_click`, `ui_start`, `ui_pause`, `ui_resume`, `ui_retry`,
  and `ui_menu`.
- Future S8 candidates: `black_hole_phase`, `black_hole_loop`,
  `black_hole_absorb`, `black_hole_finale`, `stage_fail`, and `run_end`.

The final event-key mapping, audio catalog, and runtime playback policy remain
separate S6-G1/S6-G3/S6-G4 work.
