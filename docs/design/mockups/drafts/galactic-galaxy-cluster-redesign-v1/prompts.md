# Built-in Image Generation Prompts

All three masters were generated with separate built-in image-generation calls. No reference image was edited, and no candidate used another candidate as input.

## A — Triad Cluster

```text
Use case: stylized-concept
Asset type: master source for a tiny 16x16 game ball texture, final output must be a genuine large RGBA PNG
Primary request: Create candidate A, “Triad Cluster”: a spectacular compact galaxy cluster made from exactly three clearly separated blue-violet miniature spiral galaxies, arranged as a stable triangle. Each mini galaxy has its own unmistakable gold-white nucleus and two short curved spiral arms. Pale stellar bridges and wisps of shared intergalactic gas connect all three so they read as one gravitationally bound cluster.
Scene/backdrop: genuinely transparent canvas; no visible background of any kind
Subject: one centered connected cluster object; the three galaxies and their connecting star bridges themselves form the full three-lobed outer silhouette. This must NOT be an illustration placed inside a circular ball or spherical container.
Style/medium: polished high-end 2D game sprite concept, luminous astronomical texture with crisp readable forms and controlled detail; not pixel art, but designed to survive reduction to 16x16
Composition/framing: square canvas, centered single object, generous transparent margin on every edge, no edge clipping; triangle silhouette with three distinct lobes and a connected luminous center of gravity
Lighting/mood: deep-space radiance, attractive, prestigious, wondrous
Color palette: blue, indigo, violet arms; three warm gold-to-white nuclei; faint pale-blue stellar bridges; dark gaps between nuclei for separation
Constraints: actual alpha transparency; at least 3 separate nuclei and 3 miniature spiral cues must remain visibly distinct; all three galaxies must be connected by gas/star bridges; single central object only; no detached satellite dots; no text; no frame; no checkerboard; no background plate; no drop shadow; no watermark; transparent corners and edges
Avoid: one large galaxy, supernova, black hole, event horizon, plain star pile, constellation, magic orb, crystal ball, planet, circular enclosure, glass sphere, ring-shaped container, explosion, logo, UI icon frame
```
